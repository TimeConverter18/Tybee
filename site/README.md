# Панель сотрудников Тайби

Панель работает на FastAPI и React и заменяет главный бот для сотрудников. Она предоставляет поддержку, работу с заказами, управление обложками, сотрудниками, каталогом, рассылками и финансами в соответствии с правами роли.

Подробные инструкции по запуску, входу, настройкам `.env`, сменам, резервному копированию и устройству системы находятся в [основном README](../README.md). Разделы «Avito» и «Robokassa» доступны администратору: профили и webhook Avito, параметры оплаты и режимы Robokassa хранятся в PostgreSQL и не требуют переменных окружения. Там же описаны callback и разбор ошибки 29.

Для разработки интерфейса:

```bash
cd site/frontend
npm ci
npm run dev
```

Vite слушает порт 5173 и проксирует `/api` на работающий сервер панели на порту 8000. Проверка сборки — `npm run build`.
